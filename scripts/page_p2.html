Results help

You report how many games each player has won. It is important that both players reports the results so the admin can verify the results

Intentional draws means to agree on drawing that match. When recording an intentional draw for a match result it is written as 0-0-3. If you start playing and decide to intentional draw, after a player has won a game, it has to be recorded. Therefore, the match result should be written as 1-1-1 instead of 0-0-3 or 1-0-3.

Terminology

OMW Opponents Match Win Percentage

GW Your Game win Percentage

OGW Opponents Game Win Percentage

The final standings are determined by the total points of participants. For tiebreakers you first look at OMW% then GW% and last OGW%. If there is an exceptionally rare reason and all of these three are the same. The last tiebreaker is decided by a cointoss.
