# MetaGatherer — идеи вовлечения v2: каталог фич (не только ачивки)

Апдейт после того, как выяснилось: есть **DataLens с ~2 годами данных** (паринги, стендинги,
винрейты, колоды). Это меняет оценку реализуемости почти всего. Ниже — что именно он даёт,
и большой творческий каталог идей за пределами ачивок, каждая с оценкой техреализуемости.

Легенда: **✅** делается на текущих сервисах (DataLens + БД) · **🟡** нужен доп. слой/агрегат/новый
чарт/матчинг имён · **🔴** дорого/нужна серьёзная инфра (настоящий Elo, ML-прогноз).
Источник данных помечен: `[DL]` DataLens · `[DB]` своя база (`RoundPairing`/участники) · `[IMG]`
генерация картинок (уже есть).

---

## 0. Что реально даёт DataLens (это фундамент половины идей)

Публичный дашборд, запрос по **имени игрока + период**, ответ = таблицы `[имя, матчей, winrate]`.
Уже используется в проде (уведомления по раундам). API-методы, которые уже есть в коде:

- `player_decks(игрок, период)` — на чём играл, сколько матчей, винрейт **по каждой своей деке**.
- `winrate_vs_opponents(игрок, период)` — **H2H-винрейт против каждого оппонента**.
- `winrate_vs_opponent_decks(игрок, период)` — **винрейт против каждого архетипа** (матчапы).
- `scout_opponent(игрок, оппонент, …)` — деки оппонента за период + твой H2H против него.
- Периоды: `all_time / since(дата) / last_months(n) / last_days(n)` → **«сезон» = окно периода,
  отдельная таблица сезонов НЕ нужна**. Есть фильтр по клубу.

**Что это апгрейдит:** личная аналитика, интел по оппоненту, матчап-ачивки, H2H-ачивки,
рейтинги по винрейту, «сезонность» — всё становится ✅/🟡 вместо 🔴.

**Чего DataLens НЕ даёт (остаётся на `[DB]`/AetherHub):** гранулярность матча (счёт по играм 2-1,
«камбек после 0-1», «4-0 без единой проигранной игры», «первый зарепортил»), деклисты (75 карт),
привязку к tg-аккаунту. Ключ — строка-имя, значит нужен аккуратный матчинг имён (ё/е, порядок).
И это внешний сервис Яндекса — латентность/хрупкость, кэшировать.

## 1. Личная аналитика — «узнай себя» (сильнейший драйвер регистрации)

| Идея | Оц. | Как |
|---|---|---|
| **Профиль `/me`**: сыграно, личный винрейт, любимая дека, лучший/худший матчап, немезида, стрик посещаемости | ✅ | `[DL]` decks+opponents+opp_decks, `[DB]` участие |
| **«Твой сезон в MTG»** — карточка в стиле Spotify Wrapped: топ-дека, винрейт, самый частый и самый неудобный соперник, помесячный прогресс | ✅ | `[DL]` периоды + `[IMG]` |

| **«Комфортные матчапы»** — где >60%, «фарми их» | ✅ | `[DL]` то же |

| **«Что если»-симулятор** — какой был бы винрейт, играй ты деку X весь сезон (по матрице матчапов) | 🟡 | `[DL]` матчапы + мета |

## 3. Мета-разведка — по РЕАЛЬНОМУ винрейту, а не по популярности

Сейчас граф меты = «сколько кто играет». А данные позволяют показать, что реально **выигрывает**.

| Идея | Оц. | Как |
|---|---|---|
| **Tier-list по винрейту** (а не по числу пилотов) | 🟡 | нужен агрегат по мете / отдельный DL-чарт |
| **«Недооценённые деки»** — высокий винрейт + мало пилотов (арбитраж меты, двигает разнообразие) | 🟡 | тот же агрегат |
| **«Перекупленные деки»** — много играют, винрейт низкий | 🟡 | тот же агрегат |
| **Матрица матчапов** (deck × deck winrate), как в про-мете | 🟡 | агрегат матчапов |
| **«Мета движется»** — что растёт/падает неделя к неделе, картинкой | ✅ | `[DL]` два периода + `[IMG]` |
| **Pocket-meta клуба** — чем ваш клуб отличается от общей меты | 🟡 | `[DL]` фильтр klub |
| **«Дека дня»-прогноз** — что вероятно зайдёт сегодня по тренду | 🟡 | эвристика на трендах |

## 11. Ачивки — краткая пере-оценка с учётом DataLens

DataLens вытащил большинство «дорогих» ачивок наверх:

- **Проклятый матчап, Коллекционер скальпов, Однолюб, Мультикласс, Еретик** → ✅/🟡 (матчапы и деки
  игрока есть напрямую).
- **Злейший враг, Реванш, Полиглот** → ✅ (`winrate_vs_opponents` прямо отдаёт список оппонентов и
  твой винрейт против них; «злейший враг» = мин. винрейт с ≥N матчей — бот сам покажет топ-3).
- **Гигантоубийца, сезонные топы, Донор** → 🟡 (нужен рейтинг силы; но его можно приблизить
  винрейтом+объёмом из DataLens вместо полноценного Elo — дешевле, чем я оценивал раньше).
- **Микроквесты по репортам (Камбек, Чистый лист, Win-and-in, Первый зарепортил)** → остаются на
  `[DB]`/AetherHub (нужна гранулярность матча), DataLens тут не помогает.

Итог: порог входа для ачивок сильно ниже, чем в первой версии.

## 12. Топ-ходы (если коротко, что делать)

1. **«Найди себя» + профиль `/me`** — крючок регистрации №1: у человека УЖЕ есть 2 года
   статистики, бот показывает её и говорит «привяжи аккаунт, чтобы получать это автоматически».
   ✅ дёшево, максимальный ROI.
2. **Скаут перед туром** — `scout_opponent` уже написан, осталось вшить в уведомление о раунде.
   ✅ киллер-фича, видна только зарегистрированным.
3. **«Твой сезон» картинкой** — вирусный шаринг, тянет новых. ✅ данные+картинки уже есть.
4. **Мета по винрейту (tier-list + недооценённые деки)** — уникальная польза, какой нет на графике
   популярности. 🟡 нужен один агрегат.
5. **Ачивки-микроквесты** — как еженедельный дофамин, поверх уже готовой аналитики.

## 13. Что придётся построить (энейблеры, честно)

1. **Матчинг имя↔аккаунт** надёжный (ё/е, порядок, дубли) — уже частично есть; это шея всей
   персонализации через DataLens. `[средне]`
2. **Кэш/агрегатор DataLens** — не дёргать внешний сервис на каждый запрос; предсчёт мета-агрегатов
   (tier-list, матрица) периодически. `[средне]`
3. **Слой персонализации** — `/me`, скаут, карточки поверх DataLens+DB. `[дёшево-средне]`
4. **Гранулярный матч-слой** из `RoundPairing` — только для микроквестов/стриков. `[средне]`
5. **Движок ачивок** (определения + выдача при закрытии + бэкафилл). `[средне]`
6. **Рейтинг-прокси** (винрейт+объём) вместо Elo — для лидербордов/гигантоубийцы. `[дёшево]`,
   позже настоящий Elo если понадобится `[дорого]`.

## 14. Риски

- **Матчинг имён** ошибётся → чужая статистика/победа. *Гасим:* порог уверенности + ручное слияние
  (есть) + «это ты? да/нет» при первом показе.
- **Внешняя зависимость DataLens** (латентность/поломка дашборда). *Гасим:* кэш, деградация,
  фолбэк на `[DB]`.
- **Гранулярности не хватит** для части микроквестов — честно оставить их на AetherHub-счёте.
- **Спам** — батчить в еженедельный рекап, всё под opt-in (инфра есть).
- **Эксплойты** (сговор в Реванш/Донор, накрутка pick'em) — держать «на фан», без весомых наград.
- **Приватность** — часть игроков не захочет публичной статистики; профиль публичный только с
  согласия, H2H-«немезида» показывать только тебе.
