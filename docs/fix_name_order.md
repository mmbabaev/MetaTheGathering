# Fix: порядок Фамилия Имя в таблице users

## Проблема

Часть пользователей была записана в БД с перепутанными полями:
- `first_name` содержало фамилию (Иванов)
- `last_name` содержало имя (Иван)

Отображение поломанное: бот показывал «Иван Иванов» вместо «Иванов Иван».

Причина: некоторые пользователи вводили имя в формате «Имя Фамилия» вместо «Фамилия Имя».

## Инструменты (scripts/)

| Скрипт | Назначение |
|--------|-----------|
| `dump_names.py` | Выгрузить CSV: `id,first_name,last_name` всех у кого оба поля заполнены |
| `swap_names.py` | Поменять местами first_name ↔ last_name для списка ID |
| `ids_to_swap_debug.txt` | Список ID для debug БД (57 записей, апрель 2026) |

## Процесс исправления

```bash
# 1. Выгрузить список
DATABASE_URL=postgresql://... python3 scripts/dump_names.py > /tmp/names.csv

# 2. Проанализировать список (вручную или через AI-промпт из scripts/prompt_name_check.md)
# → получить список ID для свапа

# 3. Dry-run
DATABASE_URL=... python3 scripts/swap_names.py 32 33 36 ...

# 4. Применить
DATABASE_URL=... python3 scripts/swap_names.py --apply 32 33 36 ...

# 5. Проверить дубликаты
psql $DATABASE_URL -c "
SELECT lower(last_name), lower(first_name), COUNT(*),
       string_agg(id::text || ' tg=' || tg_id::text, ', ')
FROM users
WHERE first_name != '' AND last_name != ''
GROUP BY 1, 2 HAVING COUNT(*) > 1;"

# 6. Удалить плейсхолдеры-дубликаты (предварительно перенести участия)
```
