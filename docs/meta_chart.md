# График «Метагейм-срез»

PNG-бублик со срезом метагейма турнира: сектор = архетип, размер сектора = число колод,
цвет = цветовая идентичность колоды. В центре — общее число колод, снизу — легенда в две колонки.
Под заголовком — клуб и дата («Единорог · 13.07.2026»): клуб берётся из `Tournament.club`
и пишется **текстом** (эмодзи 🦄/🐠 в DejaVu нет — вышли бы квадраты), дата — из названия
турнира, а если её там нет, то из `created_at`.

**Где:** админ-панель → «📈 Выгрузка» → «🍩 График метагейма».
Картинка уходит **только в чат нажавшего** — никаких рассылок.

Отправляется через `send_document`, а не `send_photo`: Telegram ужимает фото до 1280px
по длинной стороне и пережимает в JPEG, отчего подписи колод в высокой легенде плывут.

Рендер и (опциональный) поход в LLM синхронные, поэтому колбэк вызывает их через
`asyncio.to_thread` — иначе они заморозили бы event loop всему боту.

## Как определяется цвет колоды

Списка карт у нас нет — храним только название архетипа, поэтому цвет выводим из имени
(`services/deck_colors.py`), в три уровня:

1. **Эвристика** (`parse_color_identity`) — покрывает большинство названий:
   - гильдии/шарды/клинья: `Boros tribe` → `WR`, `Grixis Affinity` → `UBR`, `Temur control` → `URG`;
   - инициалы в верхнем регистре: `UW Familiars` → `WU`, `RG Storm` → `RG`, `WW` → `W`;
   - цветовые слова: `Blue Terror` → `U`, `Mono Black Devotion` → `B`;
   - пять цветов: `5c Domain`, `Five Color Ramp` → `WUBRG`;
   - четыре цвета: `Yore-Tiller`, `Glint-Eye` — как фразы, потому что токенизатор срезает дефис;
   - эмодзи-пометки игроков: `🟢🔵🐸 Bogles` → `UG`.

   Регистр — единственный способ отличить инициалы от обычного слова из тех же букв:
   ВЕРХНИЙ регистр до 5 букв (`UW`, `BUG`), с заглавной до 3 (`Ub`, `Bg` — так пишут в реальных
   названиях; ограничение длины не даёт `Grub` стать четырёхцветным), одна буква — только рядом
   с `mono` (`Mono U faeries`).

   **Слов «affinity»/«tron» здесь намеренно нет.** Они врут: `Flicker Tron` — синяя колода,
   а `Grixis Affinity` — `UBR`. Раньше такой маркер отдавал «бесцветная», это оседало в кэше
   навсегда, и до LLM дело не доходило.

2. **`Archetype.color_emoji`** — у засеянных архетипов он уже проставлен (`Elves` 🟢).
   Сигнал слабее имени, поэтому только когда имя не разобралось: `Grixis Affinity` помечен ⚙️,
   хотя по имени это `UBR`.

3. **LLM-фолбэк (YandexGPT)** — для флейворных имён, которые эвристика не разобрала
   (`Gates`, `Spy Combo`). Включается только при наличии ключей (см. ниже).
   Ответ проверяется строго: только буквы `WUBRG` или `C`. Не `canon()` — тот просто выкинул бы
   лишние буквы, и `{"colors":"Rakdos"}` осел бы в кэше как `R` навсегда.

4. **Дефолт** — бесцветная (серый). График никогда не падает из-за неопределённого цвета.

Результат кэшируется в `Archetype.color_identity` — LLM дёргается максимум **один раз на архетип**.
Дефолт (уровень 3) **не кэшируется**: поле остаётся `NULL`, чтобы архетип переопределился, когда
появятся ключи LLM или ручной оверрайд.

Формат `color_identity`: подмножество `WUBRG` в каноническом порядке (`"UB"`, `"URG"`),
`""` = бесцветная, `NULL` = ещё не определяли.

## Подключение YandexGPT (опционально)

Без ключей клиент выключен и работают только уровни 1 и 3 — это нормальный режим.
Чтобы включить уровень 2, добавьте в `bot/.env`:

```
YANDEX_API_KEY=<api-key из Yandex Cloud>
YANDEX_FOLDER_ID=<id каталога>
YANDEX_MODEL=yandexgpt-lite/latest   # необязательно, это значение по умолчанию
```

Расход квоты минимальный: запрос уходит только для нераспознанного архетипа и только один раз.

## Палитра

`PALETTE` в `services/deck_colors.py` покрывает **все 32 подмножества** WUBRG
(бесцветная + 5 моно + 10 гильдий + 10 шардов/клиньев + 5 четырёхцветных + WUBRG).
Ключи записаны в привычном для MTG порядке (`RW` = Boros) и канонизируются при сборке словаря,
поэтому порядок букв в ключе не важен. Полноту проверяет тест — пропущенная комбинация
иначе молча отрисовалась бы серым.

## Шрифты

`assets/fonts/` — DejaVu (Sans/Sans-Bold/Serif-Bold), лежат в репозитории, потому что Pillow
шрифты не поставляет, а на сервере кириллических TTF может не быть. Лицензия — `LICENSE-DejaVu.txt`.

## Известные ограничения (v1)

- Один цвет на **архетип**, а не на колоду конкретного игрока. Под-варианты в легенде
  (`Gates = UW · Selesnya · Naya`) требуют цвет на каждую колоду — этого мы не храним.
- Нет ручного оверрайда цвета админом: если LLM ошиблась, поле правится только в БД.
