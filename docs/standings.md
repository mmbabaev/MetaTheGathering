# Итоговые стендинги (картинка)

Список игроков турнира: **место · имя · пипы маны · колода · очки**, карточками на тёмной теме.
Топовые результаты помечены цветным акцентом слева (по очкам). Длинные списки — несколько страниц.

**Где:** админ-панель → «📈 Выгрузка» → «🏆 Итоговые стендинги» (картинки в чат нажавшего).
Плюс автоматически прикладываются к анонсу «сбор метагейма завершён» (см. [`scheduler.md`](scheduler.md)).

## Данные

`AetherhubImportService.get_standings(tournament_id) -> list[StandingRow]`:

- **все игроки из парингов**, по финальному месту (`Participant.final_place`, порядок AetherHub);
  у кого места нет (не найден в боте / не проставлено) — фолбэк по очкам, затем по имени;
- **имя** «Фамилия Имя» для найденных в боте игроков, иначе имя из парингов AetherHub;
- **колода** — только для само-зарегистрированных (иначе `—`);
- **очки**: победа 3, ничья 1, поражение 0 (стандарт Magic). Бай считается победой.

## Очки, тиры и акцент

`StandingRow.points` = `wins*3 + draws`. Цветной акцент слева по очкам за 4-раундовый турнир:

| Очки | Запись | Акцент |
|------|--------|--------|
| 12 | 4-0 | 🟩 зелёный |
| 10 | 3-0-1 и без поражений | 🟨 золотой |
| 9 | 3-1 | 🟧 оранжевый |
| < 9 | — | без акцента |

Тиры заданы по очкам, а не по точной записи — так они не зависят от числа раундов (в проде
турниры 4-раундовые, «3-1-1» из 5 раундов не встречается).

## Пипы маны

Кружки цветовой идентичности колоды (WUBRG). Цвет резолвится **по имени колоды без похода
в БД** (`deck_colors.colors_for_deck_name`: справочник → эвристика → бесцветная), поэтому
`StandingsImageService.prepare()` заполняет `StandingRow.color_identity`, а рисование остаётся
чистым CPU. Бесцветная/неизвестная колода — без пипов. Эмодзи из названия колоды вычищаются
(в DejaVu их нет — были бы квадраты).

## Страницы

`paginate()`: до **50** игроков список делят примерно **пополам** (две нестыдно-высокие
картинки); больше 50 — режут **батчами по 30**. На картинках — пагинация «N / M».
`build_standings` и кнопка/анонс отдают несколько `send_photo`.

## Потоки и стиль

Как у графика: `StandingsImageService.prepare()` (вся работа с БД) — в основном потоке,
`render_standings_pages()` (чистый CPU) — в `asyncio.to_thread` через `bot/chart.py::build_standings`.
Визуальный стиль (шрифты, фон, цвета, подзаголовок) — общий модуль `services/chart_style.py`,
тот же, что у графика.
