# Данные исследования

Файлы в этой папке подготовлены из production-базы на 06.10.2026. В репозитории
сохранены только агрегаты и обезличенные локальные метки игроков. Имена, фамилии,
username, города профиля и Telegram ID намеренно исключены.

## `events.csv`

- `track` — `edinorog_monday`, `endstep_regular` или `stilek`;
- `event_date` — дата турнира;
- `event_title` — короткое название;
- `status` — `finished` либо `registration_only`;
- `participants` — число записей в конкретном турнире.

## `cohort_summary.csv`

Агрегированные категории игроков для проверки пересечения аудиторий. Проценты
считаются внутри указанного `scope`.

## `switch_candidates.csv`

`player_id` — локальная обезличенная метка кандидата (`C01`–`C11`), не связанная
с Telegram ID или именем. Даты перечислены через `;`.

## `goldfish_events.csv`

Агрегаты всех записей Goldfish за период. `low_registration = true` означает
0–1 участника; такие строки сохранены, но на графике показаны отдельно, чтобы
не скрывать качество исходных данных.

## `candidate_goldfish.csv`

Число посещений Goldfish для 11 кандидатов, разделённое относительно даты их
первого Endstep.

## `edinorog_goldfish_flow.csv`

19 потенциальных случаев перетока после 01.09: участие в «Единороге» до
повышения цены, затем Goldfish и отсутствие «Единорога» после повышения. Это
критерий для поиска кандидатов, а не доказательство причинной миграции.
